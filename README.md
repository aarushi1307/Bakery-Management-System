# 🧁 Bakery Management System

A simple **Python + MySQL** project using **PrettyTable** to manage bakery operations from the console.

## Features
- Add, update, and delete products  
- Manage customer orders and billing  
- Display data in neat tables using PrettyTable  
- Generate daily and monthly sales reports  

## Tech Used
- Python  
- MySQL  
- PrettyTable
