# 🧁 Bakery Management System

A **Python + MySQL**–based console application for managing bakery operations.  
It features separate modes for **Admin** and **Customer**, using **PrettyTable** for neat tabular displays.

## 🚀 Features
- Admin: Add, edit, delete, search, and display employee data  
- Customer: Browse bakery and café menus and place orders  
- Password-protected admin login  
- Displays tables using PrettyTable  

## 🛠️ Tech Used
- Python (Console Application)  
- MySQL (Database)  
- PyMySQL (Database Connector)  
- PrettyTable (Output Formatting)  

## ⚙️ How to Run
1. Ensure your MySQL server is running and has a database named `bakery`.  
2. Tables used: `employee`, `item`, `flavours`, and `cafe`.  
3. Open a terminal in the project folder and run:

   python "BAKERY MANAGEMENT SYSTEM AARUSHI12C.py"
